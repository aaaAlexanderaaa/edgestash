# EdgeStash

[English](README.md)

把窗口收到屏幕边缘，需要时再唤出。这是一个只在本机运行的 macOS 菜单栏应用。

当前发布的安装包只支持 Apple 芯片（M 系列），不支持 Intel。

## 外侧边和共享边

一块屏幕的边分两种，EdgeStash 对它们的处理不一样。

**外侧边**不挨着另一块屏。窗口可以从这一侧滑出屏幕，桌面上不再占地方。边上会留一条细的提示，鼠标悬停或点一下就能唤回。

**共享边**是两块屏贴在一起的那条线，比如笔记本和外接显示器相接的地方。如果还把窗口往这一侧「滑出去」，它会落到旁边那块屏上，或者卡在两块屏中间。所以 EdgeStash 会让 macOS 把窗口最小化：窗口真正离开屏幕，提示留在原来那块屏上。

共享边这条路径需要 macOS 26.4。更早的系统外侧边照常可用；共享边不会收纳，以免窗口被绑到错误的桌面。

## 系统要求

- Apple 芯片 Mac
- 外侧边收纳：macOS 12 或更高
- 共享边收纳：macOS 26.4 或更高

## 安装

1. 从 [Releases](https://github.com/aaaAlexanderaaa/edgestash/releases/latest) 下载 `EdgeStash.zip`。
2. 解压，把 `EdgeStash.app` 放到「应用程序」。
3. 打开应用。第一次请授予辅助功能权限（系统设置 → 隐私与安全性 → 辅助功能）。没有权限时设置页会自己打开；授权之后从菜单栏图标再打开即可。
4. 若系统提示无法验证开发者：按住 Control 点击应用，选择「打开」。

## 用法

- 把窗口拖到屏幕边缘并停住，就会收进去。
- 鼠标悬停或点击边上的提示即可唤出。
- 菜单栏图标打开设置：选择应用、收纳边、外观和快捷键。

## 隐私

只在这台 Mac 上工作。不上网、不遥测、不截屏。辅助功能只用来移动和恢复窗口。
