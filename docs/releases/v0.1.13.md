# EdgeStash 0.1.13 — Order-independent multi-display restoration and low WindowServer overhead

This non-latest prerelease addresses multi-display plug/unplug consistency,
geometry preservation, cross-version WindowServer/AX reliability, and
background performance. It continues the Release-optimized diagnostic package
used by 0.1.12.

## Changes

- **Order-independent multi-display restoration:** Preserve per-window home
  anchors (display, edge, original preferred size, and normalized vertical
  position) across configured drops and unconfigured intermediate sets so
  unplugging and replugging displays in any order restores windows to where
  they originally belonged.
- **Exact size and usable-area restoration:** Preserve each stashed window's
  `preferredSize` and normalized `relativeY` non-destructively across smaller
  displays and fallback scatters, clamp rebased and scattered frames against
  each display's `visibleFrame` (clear of menu bars and the Dock), use
  cross-display safe AX frame writes (`AXEnhancedUserInterface` temporarily
  suspended during repositioning, move-then-resize-then-move when crossing
  displays or growing), and tolerate menu-bar clamping and character-cell size
  increments on reveal.
- **Route A lazy seam conversion & async seam reveal:** Keep already-minimized
  collapsed seam stashes minimized lazily when a neighbor display unplugs
  instead of forcing an online deminimize-and-re-park transition during
  hotplug; convert naturally on the next reveal and re-collapse. Confirm
  asynchronous `AXMinimized` reveals within the 1.5-second settle bound instead
  of prematurely re-minimizing slow apps.
- **Eliminate outer-edge `alpha == 1` recovery deadlock & enable occlusion:**
  Park exposed outer-edge stashes completely offscreen (`edgeLip = 0`) so macOS
  marks them occluded (`NSWindow.OcclusionState.visible == false`) and stops
  hidden WindowServer/GPU rendering, while still applying `alpha = 0` for apps
  whose frame constraints clamp a lip back onto the screen. Post-write
  confirmation accepts zero-overlap offscreen frames and acknowledged
  zero-alpha clamped frames without deadlocking when `CGWindowList` reports
  `alpha = 1`.
- **Reliable multi-display topology & sleep detection:** Stabilize unit-number
  fallback display IDs so connecting a second identical display does not rename
  the first, use direct Quartz `CGDisplayBounds` geometry, freeze unsolicited
  geometry detachment during `CGDisplayRegisterReconfigurationCallback`,
  resolve minor vertical-stagger jitter when matching configured screen sets,
  preserve surviving-display retries across quiet increments, and measure real
  kernel sleep time (`mach_continuous_time - mach_absolute_time`) instead of
  raw wall-clock timer lag.
- **Eliminate sustained WindowServer and background overhead:** Make global
  `mouseMoved` monitoring and minimize polling demand-driven (zero mouse-move
  IPC wakeups without collapsed seam beacons, zero minimize timer ticks without
  collapsed seam or pending write confirmations), cache display geometries for
  approach evaluation, relax steady-state discovery/trust timers, bound AX IPC
  timeouts, batch `CGWindowListCopyWindowInfo` snapshots once per recovery pass,
  size transient flourish panels tightly to the 5pt rail instead of the full
  display, and stop rewriting `store.json` on every rescue journal update.

## Install and test

1. Download `EdgeStash.zip` from this release (or use `dist/EdgeStash.app` from
   a local build).
2. **Quit the running EdgeStash first**, allowing managed windows to restore.
   Extract the archive, replace the app and reopen it. `dist/CURRENT.txt`
   records package details.
3. Test plugging and unplugging displays in different orders, mixed
   resolutions/menu bars, multi-window apps (including Stickies, browsers,
   Electron apps, and terminals), sleep/wake, and Activity Monitor CPU/GPU usage
   for EdgeStash and WindowServer. If a symptom recurs, record its time and
   promptly copy `~/Library/Logs/EdgeStash/`.

Apple Silicon only. Outer edges require macOS 12 or later; shared seams require
macOS 26.4 or later and supported runtime capabilities. This Release-optimized
package enables bounded local diagnostics. Logs contain no window titles,
document contents, keystrokes or pixels and are never uploaded automatically.

The app is ad-hoc signed and unnotarized, with no installable Homebrew Cask.
Accessibility may need to be granted again after updating. The existing latest
release remains unchanged.

## Verification scope

Verified locally with the expectation check and full logic suite (including
18,432 configured round-trip timelines, 1,512 subset return timelines, and
unconfigured intermediate commutativity), live `ScreenSetCoordinator` adapter
replay (319 assertions), live `StashSession`/`StashEngine`/`StashMergeCoordinator`
recovery replay (76 assertions), isolated native adapter checks, distribution
tooling checks, and CLT Debug and diagnostic Release builds with strict
`codesign` verification.

Full Xcode-project Debug CI (`EdgeStash.xcodeproj`) and physical multi-display
macOS 27 / Activity Monitor acceptance remain open. Local CLT builds and
injected replays do not prove physical display enumeration, native AX timing, or
perceptual outcomes.
