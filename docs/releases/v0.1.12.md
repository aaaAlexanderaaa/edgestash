# EdgeStash 0.1.12 — Shared presentation ownership

This non-latest prerelease fixes five related consistency defects through shared
request admission, operation ownership and command scope. It continues the
Release-optimized diagnostic package used by 0.1.11.

## Changes

- Preserve the desired appearance while recovery hands a queued request to the
  next main-queue turn. Consecutive toggles retain their parity; a newer explicit
  close cancels an older reveal even when the window is already collapsed.
- Apply the same settled-state and revision checks to marker and merged hover.
  An old dwell cannot replace a newer explicit close or rearm during a reveal.
- Freeze application/show-all command scope before executing members. A window
  awaiting control is skipped and diagnosed, allowing healthy siblings to keep
  responding. Recent-window scope also selects a controllable managed member.
- Make merged strips project window state without issuing implicit closes.
  All-managed, show-all and independent app commands can leave several merged
  members expanded. Pins keep their protection and visual highlight preference;
  normal leave-collapse still applies independently.
- Refresh hidden presentation when the window's occupied edge segment changes
  between exposed and shared, including staggered-display reflow and increments.
  Unchanged sibling segments and duplicate observations stay quiet.
- Separate input revision from native operation identity, reject superseded
  callbacks and recheck pin/control protection before deferred execution.
- Add bounded local operation diagnostics and regression timelines through the
  actual session methods, engine commands and full merge coordinator.

## Install and test

1. Download `EdgeStash.zip` from this release.
2. **Quit the running EdgeStash first**, allowing managed windows to restore.
   Extract the archive, replace the app and reopen it. Source builds use
   `dist/EdgeStash.app`; `dist/CURRENT.txt` records package details.
3. Exercise repeated shortcuts, several windows/apps sharing a merged rail,
   show-all, staggered display changes and sleep/wake. If a symptom recurs, record
   its time and promptly copy `~/Library/Logs/EdgeStash/`.

Apple Silicon only. Outer edges require macOS 12 or later; shared seams require
macOS 26.4 or later and supported runtime capabilities. This Release-optimized
package enables bounded local diagnostics. Logs contain no window titles,
document contents, keystrokes or pixels and are never uploaded automatically.

The app is ad-hoc signed and unnotarized, with no installable Homebrew Cask.
Accessibility may need to be granted again after updating. The existing latest
release remains unchanged.

## Verification scope

The release is gated on the expectation check and full logic suite, current
session/engine/merge and screen-set coordinator replays, isolated native adapter
checks, Debug and diagnostic Release builds, archive/signature verification and
full Xcode-project Debug CI for the exact release commit. The release body links
that final CI run; the accompanying verification record lists measured results.
Twelve presentation anchors remain declared: one executable and eleven
structural-only cardinality rows.

Physical macOS 27 multi-display sleep/wake, cross-app AX/input, WindowServer
performance and owner perceptual acceptance remain open. Injected completion
timelines and successful builds do not prove those physical outcomes.
