# EdgeStash 0.1.10 — English interface and screen-set regression coverage

This diagnostic prerelease integrates the 0.1.9 reliability fixes with display
connection-order regression coverage and makes the application and project
English-only, except for `README_cn.md`.

## Changes

- Repair the independent live-coordinator replay for the newer recovery API.
  Space/persistence refusal retains intent and avoids desktop scatter while using
  the existing bounded retry budget. Failed-capture visibility debt and stale
  intermediate recovery are covered without changing the product coordinator.
- Run the coordinator replay in CI, alongside the existing contract, logic,
  native-adapter, distribution-tool, and Xcode Debug checks.
- Use the English application catalog regardless of system locale or legacy
  language selection. Remove the obsolete language picker while preserving older
  preference documents and rescue data.
- Translate project documents, historical quotations, diagnostics, and release
  text into English. Historical verification retains its original scope and
  source hashes. `README_cn.md` remains the Chinese introduction.
- Add a standing project-language and copy-identifier check to prevent regressions.

## Install and test

1. Download `EdgeStash.zip` from this release.
2. **Quit the running EdgeStash first**, allowing managed windows to restore.
   Extract the archive, replace the app, and reopen it. Source builds use
   `dist/EdgeStash.app`; `dist/CURRENT.txt` records the package details.
3. Check the English interface and normal capture/reveal/collapse behavior. For
   sleep/wake investigation, preserve the usual display setup, note reproduction
   time, and promptly copy `~/Library/Logs/EdgeStash/`.

Apple Silicon only. Outer edges require macOS 12 or later; shared seams require
macOS 26.4 or later and supported runtime capabilities. This package uses Release
optimization with local diagnostics enabled. Logs stay local without automatic
upload and contain no window titles, document contents, keystrokes, or pixels.

The package is ad-hoc signed and unnotarized. It is a diagnostic test build,
without an installable Homebrew Cask. Accessibility may need to be granted again
after an update.
